# Secretário IA Empresarial

## Objetivo

Desenvolver um agente de inteligência artificial capaz de responder perguntas sobre uma empresa utilizando simultaneamente:

- Banco de dados corporativo;
- Documentos internos (RAG);
- Informações externas obtidas na Web.

O sistema atuará como um Secretário Corporativo Inteligente, integrando informações de diferentes setores da empresa para fornecer respostas fundamentadas e auxiliar gestores na tomada de decisão.

---

## Tecnologias

- Python
- SQLAlchemy
- SQLite
- LangChain
- LangGraph
- Gemini
- Tavily
- Streamlit
